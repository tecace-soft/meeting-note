h1. Meeting Note Mobile Developer Handoff

h2. Overview

Meeting Note Mobile is a Flutter mobile app for the existing Meeting Note product. It currently targets Android first, with iOS scaffolded but not production-configured yet.

The app connects to the same Supabase data layer and workflow backend used by the Meeting Note web app.

h2. Transcription / Summary Flow

# User records audio or selects an audio file.
# Mobile uploads audio to Supabase Storage bucket {code}meeting-recordings{code}.
# Mobile inserts a {code}file{code} row.
# Mobile creates a signed Supabase Storage URL.
# Mobile submits the signed URL to the workflow backend.
# Workflow backend runs transcription and summary generation.
# Mobile polls the workflow job endpoint.
# Workflow backend creates/updates the final {code}note{code} data.
# Mobile navigates to the summary/transcript detail screen.

Workflow endpoints:

{code}
POST /summarize-audio/jobs
GET  /summarize-audio/jobs/:jobId
{code}

Workflow request fields:

* {code}downloadUrl{code}: signed Supabase audio URL
* {code}fileName{code}: audio file name
* {code}fileId{code}: file table id
* {code}meetingAt{code}: ISO timestamp
* {code}userTimeZone{code}: device timezone
* {code}instructions{code}: optional user instructions
* {code}promptId{code}: summary_prompt id
* {code}userId{code}: authenticated user id
* {code}userName{code}: display name
* {code}noteId{code}: uuid generated by app
* {code}language{code}: {code}en{code} or {code}ko{code}
* {code}attachments{code}: base64 attachment objects

h2. Attachments

Mobile supports file attachments and camera photos during note creation.

Current behavior:

* Attachments are sent to the workflow backend as base64 objects.
* After the workflow job completes, attachments are saved to Supabase Storage bucket {code}meeting-note-images{code}.
* Attachment metadata is inserted into {code}note_image{code}.

Attachment limits currently enforced by mobile:

* Up to 10 attachments per note
* Max 25 MB per attachment sent to workflow
* Max 50 MB total attachments sent to workflow
* Max 50 MB per attachment stored after completion

Supported attachment types include PDFs, text files, images, audio, and video.
