## 웹 동작

수동 지정은 메뉴가 닫힌 뒤 전사 상단에, 제안 수락은 제안 카드 아래에 이름과 공유 동작을 표시한다.
마지막 익명 화자의 이름을 정해 제안 카드가 사라져도 공유 동작은 남는다.
같은 사람은 한 번만 표시하고 본인은 공유 대상에서 제외한다.
이름이나 이메일만으로 공유 대상을 추정하지 않는다.
제안의 저장된 화자 id는 해당 화자 행의 이름과도 일치해야 하며 Microsoft 연락처를 직접 선택한 경우에는 그 연락처의 object id를 쓴다.
소유자와 공유 목록은 읽기로 확인하고 버튼 클릭 직전에 다시 읽는다.
한 사람 추가 버튼은 읽었던 shared_users의 정확한 값도 UPDATE 조건으로 검사하며 읽기와 쓰기 사이의 다른 탭 변경을 덮어쓰지 않는다.
NULL과 빈 배열을 구분하고 경합으로 0행이면 최신 목록을 다시 읽어 같은 대상만 추가하며 최대 세 번까지만 시도한다.
재시도에서도 소유권과 현재 지정 대상을 확인하고 상한에 도달하면 오류를 표시한다.
읽기 실패와 권한 거부는 표시하고 0행 쓰기를 성공으로 알리지 않는다.
이미 직접 공유된 사람은 공유됨으로 표시하며 다시 쓰지 않는다.
공유 버튼을 누르지 않고 닫거나 이름을 다시 고치거나 초기화해도 기존 공유 목록은 유지한다.
프로젝트 공유와 AX-KH 참석자 확인을 이름 지정에 묶지 않는다.

## 적용 범위와 이력

새 노트 화면과 녹음 기록 화면에 같은 공유 동작을 적용한다.
계정 id가 없는 사람의 공유 대상 선택은 각 화면의 기존 공유 창을 재사용하며 창을 여는 것만으로 쓰지 않는다.
기존 공유 창도 강화된 setNoteSharedUsersAsOwner를 사용하므로 0행 갱신 시 닫히거나 성공을 알리지 않는다.
이 결정은 DEC-0024의 제안 및 자동 요약 갱신 정책을 보완하며 대체하지 않는다.
기존 노트의 공유를 철회하는 migration이나 backfill은 만들지 않는다.
모바일과 C1 파일은 이 웹 PR에서 변경하지 않는다.
제품 문서 본문은 유지하고 Andrew의 docs:verify 일괄 서명 때 화자 지정과 공유 분리 안내를 반영한다.
